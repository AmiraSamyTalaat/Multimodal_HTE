# Reproduction tools for the archived original benchmark

The Python scripts in this directory were preserved from the original reviewer reproducibility package. They regenerate original benchmark figures and table summaries from the original analysis matrix and stage aggregate result files. The private linked-cohort matrix is not redistributed here.

`VERIFY_MANUSCRIPT_NUMBERS.py` checks the original (pre-review) locked paper values. `REGENERATE_MANUSCRIPT_OUTPUTS.py` rebuilds those original aggregate artifacts. The new manuscript also contains analyses generated by the `postreview/` and `corrective/` code trees; original-only verification does not cover their additional outputs.

For a full re-training from source, reconstruct the source data from GEO in a private working environment and follow the recorded original configuration and script CLI options. Package-level SHA-256 integrity is checked with the top-level `VERIFY_RELEASE.py`.
